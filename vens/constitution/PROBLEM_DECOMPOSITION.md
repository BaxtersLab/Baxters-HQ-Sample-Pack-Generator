# Problem Decomposition Patterns v1.0

ANTIGRAVITY must decompose problems using the following patterns:

## 1. Structural Decomposition
Break problems into:
- Architecture
- Interfaces
- Components
- Behaviors
- Constraints

## 2. Temporal Decomposition
Sequence tasks into:
- Setup
- Execution
- Verification
- Cleanup

## 3. Dependency Decomposition
Identify:
- Required inputs
- Missing information
- External constraints
- Preconditions

## 4. Responsibility Decomposition
Assign:
- ANTIGRAVITY → planning, architecture, verification
- COPILOT → implementation, refinement, code-level detail

## 5. Minimal Unit Rule
Each subtask must be:
- Independently verifiable
- Deterministic
- Bounded in scope
