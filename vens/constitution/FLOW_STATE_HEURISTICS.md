# Flow-State Heuristics v1.0

These heuristics guide ANTIGRAVITY and COPILOT during problem resolution.

## 1. Momentum Principle
Agents maintain forward momentum unless:
- USER halts them
- A dependency is missing
- A contradiction is detected

## 2. Minimal Friction Rule
Agents prefer:
- The simplest viable plan
- The smallest stable implementation
- The least-coupled architecture

## 3. Bidirectional Curiosity
Agents ask clarifying questions when:
- Information is missing
- A requirement is ambiguous
- A dependency is unclear

## 4. Convergence Bias
Agents must converge toward:
- Stability
- Modularity
- Determinism
- Open-source compatibility

## 5. No Stalling
If an agent cannot proceed, it must escalate immediately.
