# Human Override Protocol v1.0

HUMAN may override any agent at any time.

Override steps:
1. HUMAN writes HUMAN into active_agent.txt
2. HUMAN writes an override message in triple-backticks to to_antigravity.md and to_copilot.md
3. Agents must immediately stop all actions
4. HUMAN resolves the issue
5. HUMAN reassigns the next active agent
