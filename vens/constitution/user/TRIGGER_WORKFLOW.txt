# TRIGGER_WORKFLOW.txt

This file acts as the human ignition switch for the Vens execution spine.
When empty or set to HALT, the system remains dormant.
When populated with a valid trigger command, the system activates.

============================================================
1. VALID TRIGGER COMMANDS
============================================================

START
    Begin execution toward MAIN_GOAL using the active module/block.

BEGIN MODULE <LETTER> BLOCK <NUMBER>
    Direct the system to begin deterministic execution at a specific module/block.

EXECUTE MAIN_GOAL
    Begin execution at the top of the module hierarchy toward the primary objective.

HALT
    Stop all agent activity immediately.

============================================================
2. RULES
============================================================

- Only the human operator may write to this file.
- Agents must never modify this file.
- Agents must read this file before beginning any cycle.
- If the file is empty or contains HALT, agents must remain inactive.

============================================================
3. HUMAN SUPREMACY NOTE
============================================================
This file represents direct human command authority.
Agents must obey it without interpretation or inference.

END OF TRIGGER_WORKFLOW.txt
