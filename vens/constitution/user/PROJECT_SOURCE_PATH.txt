# PROJECT_SOURCE_PATH.txt

This file defines the absolute path to the project's local repository.
Agents must read this file to determine where source files live.

============================================================
PROJECT NAME: (your project name here)
SOURCE PATH: (absolute path to local repo here)
============================================================

Example:
PROJECT NAME: MyApp
SOURCE PATH: C:\Users\Baxter\Desktop\MyApp

Rules:
- Only HUMAN may modify this file.
- Agents must never modify this file.
- Agents must use this path as the root for all build and app files.

END OF PROJECT_SOURCE_PATH.txt
