# Implementation Refinement Loop v1.0

This loop governs ANTIGRAVITY ↔ COPILOT collaboration.

## 1. ANTIGRAVITY → COPILOT
ANTIGRAVITY sends:
- A scoped subtask
- Constraints
- Acceptance criteria

## 2. COPILOT → ANTIGRAVITY
COPILOT returns:
- Implementation
- Notes
- Deviations (if any)

## 3. ANTIGRAVITY Verification
ANTIGRAVITY checks:
- Determinism
- Stability
- Alignment with constraints
- Compliance with both constitutions

## 4. Iteration
If refinement is needed:
ANTIGRAVITY issues a new subtask.

## 5. Completion
When stable:
ANTIGRAVITY finalizes the task and reports to USER.
