BSPG — Baxters Sample Pack Generator

This folder contains a minimal scaffold for the BSPG project used by the GUI wrapper.

Structure:
- `bspg/` Python package
- `bspg/core/`, `bspg/backend_adapter/`, `bspg/gui/`, `bspg/utils/`
- basic tests to verify imports

This scaffold is intentionally minimal and contains no DSP or GUI implementation code.
